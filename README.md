# 予約ちゃん（東村山LIFE整体院）

スタッフ用の予約表（色＋名前）と、患者向けの空き表示（○・要相談・×）を1つで動かすアプリです。
スプレッドシートの代わりに、予約ちゃん自身がデータを持ちます。

| 使い方 | 中身 |
|---|---|
| 患者向けページ | `https://（サイト）/` … ○△× だけ。名前はサーバーから一切返しません |
| スタッフ用（スマホ・PCのブラウザ） | `https://（サイト）/edit.html` … パスワードでログイン |
| スマホアプリ | 上の edit.html を開いて「ホーム画面に追加」 |
| PCソフト（Electron） | `desktop/` をビルド。中身は edit.html を専用ウィンドウで開くだけ |

スマホ・PC・ブラウザのどれで入れても同じデータです（Netlify Blobs に保存）。

---

## 1. Netlify に置く（新しいサイトとして。本番の空き時間確認サイトとは別）

1. このフォルダを GitHub の新しいリポジトリに入れる（または Netlify にドラッグ＆ドロップ）
2. Netlify で新しいサイトを作る（ビルド設定は `netlify.toml` に書いてあるので変更不要）
3. **環境変数**（Site configuration → Environment variables）

| 名前 | 内容 | 必須 |
|---|---|---|
| `YOYAKU_PASSWORD` | 最初のパスワード（任意。入れなければ **0000**）。ログイン後に ☰ →「パスワード変更」で変えるのがおすすめ | 任意 |
| `YOYAKU_SECRET` | ログイン用の秘密の文字列（任意。入れなければ初回に自動で作られます） | 任意 |
| `GOOGLE_SPREADSHEET_ID` | 取り込み元のシートID（既存サイトと同じ値） | 取り込み時のみ |
| `GOOGLE_SHEET_NAME` | `CMYK臨時予約表` | 取り込み時のみ |
| `GOOGLE_SERVICE_ACCOUNT_KEY` | サービスアカウントのJSON（既存サイトと同じ値） | 取り込み時のみ |
| `PUBLIC_DAYS_AHEAD` | 患者向けに何日先まで表示するか（既定 90）。それより先は「－」 | 任意 |

Google の3つは、取り込みが終わったら削除してかまいません（削除するとシートには一切アクセスしなくなります）。

## 2. スプレッドシートからの取り込み（移行時）

edit.html → ☰ → 「スプレッドシートから取り込み」
- 「確認だけ」で件数を確認 → 「取り込む」で保存（指定期間の日は**上書き**）
- 色の割り当て：ピンク(マゼンタ)→ピンク / 赤→赤 / 濃いグレー→グレー / 青・シアン→青 / 薄い水色→薄水色（区切り・空き） / 白→なし
- 想定外の色はグレー（埋まり扱い）として取り込み、件数を表示します
- セルの文字は名前として取り込みます（20文字まで）

## 3. 色の意味

| 色 | 患者向けの判定 |
|---|---|
| ピンク・青・赤・グレー | 埋まり |
| 薄水色 | 空き（隣の予約と区別するための区切り。予約ではない） |
| なし | 空き |

判定ルールは今のサイトと同じです（施術60分＋前後30分。施術時間が埋まり→×、前後だけ埋まり→要相談、日曜は自動で休）。
日付の見出しをタップすると、その日を「休診」にできます。

## 4. メニュー（☰）の各ページ

| ページ | できること |
|---|---|
| 月の予約記録 | A4横1枚（予約表と同じ並び）のPDF、会計くん用CSV |
| 固定予約・週のコピー | 名前＋曜日＋時刻＋長さを登録して期間内にまとめて反映／ある週（月〜土）を別の週へ繰り返しコピー（1〜12週・無期限）。重なる予約は入れずに一覧で知らせる。繰り返しで入った予約は ↻ 付きで表示され、タップすると今日以降の同じ繰り返し予約をまとめて削除できる |
| キャンセル統計 | 月ごとのキャンセル件数・率、いつキャンセルされたか（当日・前日…）、一覧 |
| 稼働率 | 月・日ごとの稼働率（予約が入っている時間 ÷ 営業時間） |
| 設定 | 予約の長さの選択肢（10分〜180分・当日全て）と初期の長さ |

予約をタップしたときの「キャンセル」は統計に残り、「消す」は記録に残りません（入力ミスの修正用）。

## ログインとパスワード

- 各端末で**最初の1回だけ**ログインが必要です（それ以降、起動すると予約ちゃんから始まります）。その後はアプリ・サイトを開くとそのまま本体が表示され、☰ →「ログアウト」したときだけログイン画面になります（ログインは1年間有効）。
- パスワードの初期値は **0000**。☰ →「パスワード変更」で変えられます。変えると、ほかの端末はログアウトされます。
- 続けて10回間違えると15分間ログインできなくなります（総当たり対策）。

## 予約ちゃん2

- ログアウトしてログイン画面で **test** と入れると「予約ちゃん2」が開きます（**0000**〔または変更後のパスワード〕なら予約ちゃん）。
- 予約ちゃん2のデータは、その端末の中だけに保存されます（サーバーには送りません）。患者向けの○×表とパスワード変更はありません。
- 予約ちゃんの「バックアップを保存」したファイルを、予約ちゃん2の「バックアップから復元」で読み込めます。

## 5. バックアップ

edit.html → ☰ → 「バックアップを保存（JSON）」。**週1回程度の保存をおすすめします**。
「バックアップから復元」で、ファイルに含まれる日だけを上書きして戻せます。
※ 予約表に加えて、設定・固定予約・キャンセル記録も一緒に保存・復元されます。

## 6. PCソフト（Electron）を作る

```
cd desktop
（config.json の url を実際のサイトの edit.html に書き換える）
npm install
npm run dist      → dist フォルダに Windows 用インストーラーができます
```
パソコンには患者データを保存しません（ログイン状態だけ保持）。ネットにつながっていないと開けません。

## 7. 手元での動作確認（開発用）

```
YOYAKU_PASSWORD=test-pass-1234 YOYAKU_SECRET=（32文字以上） node dev/server.mjs   → http://localhost:8888
node dev/test.mjs   → 自動テスト
```
